===============================
Inventory Report (mj_inventory_report)
===============================

This module provides a structured Inventory Report system for inventory management in Odoo. 
This module consists of two main reports:
1. Product-wise Inventory Report: Displays opening stock, inward quantity, outward quantity, and closing stock for a specified date range and location.
2. Material Receive Report (Purchase): Shows details of received materials including date, supplier name, quantity, unit, unit cost, and total cost. Only validated (Done) receipts created from a Purchase Order are included; manual receipts are not shown.

====================================
Features
====================================

- Product-wise inventory report with opening, inward, outward, and closing stock for a given date range and location.
- Material Receive Report with date, supplier name, quantity, unit, unit cost, total cost (validated receipts from Purchase Orders only).
- User-friendly interface with filters and grouping options.
- Access control for secure data management.


====================================
Installation
====================================

1. Place the module in your custom addons directory
2. Update apps list
3. Install **Inventory Report (mj_inventory_report)** module from the Apps menu.
